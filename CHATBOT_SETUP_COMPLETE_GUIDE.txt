STEP 11: MONITOR & OPTIMIZE API USAGE
================================================================================

Google Gemini free tier has limits. Monitor to avoid exceeding them.

CHECKING USAGE:

1. Go to: https://aistudio.google.com/

2. Look for:
   - Total API calls made
   - Tokens used
   - Current usage percentage
   - Remaining quota

3. FREE TIER LIMITS:
   - 60 requests per minute
   - Unlimited total requests (but may have daily limits)
   - No credit card required
   - No automatic billing

SETTING UP BUDGET ALERTS (for paid tier if upgrade):

1. Go to: https://console.cloud.google.com/

2. Billing section:
   - Set budget caps
   - Get email alerts when approaching limit
   - Never get surprise charges

OPTIMIZATION TIPS:

1. If API usage is HIGH:
   - Go back to n8n workflow
   - Find "Max Output Tokens" setting in Gemini node
   - Lower it from 300 to 200 (shorter responses = fewer tokens)
   - Save and test

2. If responses are SLOW:
   - Normal for free tier
   - Gemini can take 1-3 seconds sometimes
   - No way to make it faster unless upgrading to paid

3. If getting rate limit errors:
   - Implement rate limiting (advanced)
   - Or just wait a bit before sending next message
   - Free tier allows 60 requests/minute = 1 per second

MONITOR REGULARLY:
- Check usage every few days
- Look for unusual spikes
- Know your monthly pattern

================================================================================
TROUBLESHOOTING REFERENCE
================================================================================

PROBLEM: "Webhook not registered" error

SOLUTIONS:
1. Check if workflow is ACTIVE (Step 8)
   - Toggle should be GREEN
   - Status should say "Active"
2. Click "Execute Workflow" button and try curl test again
3. Wait 10 seconds and retry

---

PROBLEM: Empty response from chatbot

SOLUTIONS:
1. Check n8n Executions tab for errors
2. Verify Gemini API key is valid
3. Check if input prompt is correct ({{ $json.message }})
4. Check Response Data field is set to {{ $json.text }}
5. Try increasing max_output_tokens to 500

---

PROBLEM: Chatbot is very slow (5+ seconds)

SOLUTIONS:
1. This is normal for Google Gemini free tier sometimes
2. Increase timeout in ChatBot.tsx if needed
3. Let it finish loading (don't click while loading)
4. If consistently slow, upgrade to paid Gemini tier

---

PROBLEM: Browser shows CORS error

SOLUTIONS:
1. This shouldn't happen with n8n webhooks
2. Check webhook URL doesn't have /test/ anymore
3. Make sure workflow is ACTIVE
4. Try refreshing page

---

PROBLEM: API says "rate limit exceeded"

SOLUTIONS:
1. Wait 1-2 minutes before sending more messages
2. Free tier: 60 requests per minute limit
3. Don't spam messages - space them out
4. If need more, upgrade to paid tier

---

PROBLEM: Chatbot works locally but not on production

SOLUTIONS:
1. Double-check webhook URL in ChatBot.tsx
2. Make sure you changed from /webhook-test/ to /webhook/
3. Rebuild project: npm run build
4. Redeploy to hosting
5. Clear browser cache (Ctrl+F5)
